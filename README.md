# listagent Windows 便携版

这是一个本地运行的桌宠智能体。程序目录自带 Electron 运行时，目标电脑无需预装 Node.js；双击 `start-listagent.cmd` 即可启动。

## 首次使用

1. 启动后打开控制面板。
2. 在“模型/API”中分别填写文本模型和视觉模型的平台 URL、API Key 与模型名。
3. 在“人格”中填写人格设定、语言示例和“使用者关系”。
4. 在“形象/皮肤”中选择静止、移动和删除动画；程序会把运行配置写入本目录的 `data` 文件夹。

本便携包不包含任何个人 API Key、人格附件、聊天历史、电脑路径、微信截图、训练数据或训练环境；可选的 YOLO 气泡模型作为独立模型文件随 Release 提供。首次启动会在本机自动生成空白配置。

## 运行能力

- 桌宠拖动、吸附到窗口、随机移动和多皮肤切换。
- 文本模型对话、视觉模型识图、天气/时间等联网查询（需要配置相应 API）。
- 在用户授权后打开应用、读写文本/Word 文档以及处理文件操作。
- 微信自动监听需要用户自行配置本地气泡检测组件；便携包可直接使用随 Release 提供的 YOLO 气泡模型，但不包含训练环境和数据集。

## 数据位置

- `data`：本机运行配置、人格、对话和调试截图。
- `.runtime`：Electron 运行时缓存。

这些目录均在便携包内生成，复制整个文件夹即可迁移配置。请勿把 API Key 提交到公共仓库或发送给他人。

## 开发检查

在 PowerShell 中运行：

```powershell
npm run check
npm test
```

## 卸载

双击项目根目录的 `uninstall-listagent.cmd`，输入 `DELETE` 后会停止本版本进程、移除本版本写入的资源管理器右键菜单，并删除当前安装目录。它不会触碰另一份安装或其他版本的注册表项。

## GitHub 更新

在控制面板“连接”页面填写公开仓库的 `owner/repository`，即可检查 GitHub Releases 并一键下载更新。更新程序只替换程序文件，保留每位使用者的 `data`、`.runtime` 和本地素材。发布新版本时推送形如 `v0.2.1` 的标签，GitHub Actions 会自动构建 Windows 便携包并创建 Release。
