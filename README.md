# listagent Windows 便携版

这是一个本地运行的桌宠智能体。程序目录自带 Electron 运行时，目标电脑无需预装 Node.js；双击 `start-listagent.cmd` 即可启动。

## 首次使用

1. 启动后打开控制面板。
2. 在“模型/API”中分别填写文本模型和视觉模型的平台 URL、API Key 与模型名。
3. 在“人格”中填写人格设定、语言示例和“使用者关系”。
4. 在“形象/皮肤”中分别选择坐立、站立、互动、移动和删除动画；程序会把运行配置写入本目录的 `data` 文件夹。

本便携包不包含任何个人 API Key、人格附件、聊天历史、电脑路径、微信截图、训练数据或训练环境；可选的 YOLO 气泡模型作为独立模型文件随 Release 提供。首次启动会在本机自动生成空白配置。

## 运行能力

- 桌宠拖动、吸附到窗口、随机移动和多皮肤切换（含“佩佩”章节编辑风皮肤）。
- 形象与人格页可分别上传坐立、站立、互动、移动和删除 GIF/WebM，并独立调整大小；移动结束后随机显示坐立或站立，窗口吸附时固定坐立，静止时左键单击播放一次互动动画（互动文件上限 100MB，其余上限 40MB）。
- 文本模型对话、视觉模型识图、天气/时间等联网查询（需要配置相应 API）。
- 可选的人文关怀提醒：根据连续活跃时长、系统空闲状态和当前时间，用完整人格设定生成自然的休息、饮水、活动或晚间收尾提示，并通过轻量气泡显示；默认最短间隔 45 分钟、连续使用 90 分钟后提醒，可在“自动化与微信”页面关闭或调整。
- 在用户授权后打开应用、读写文本/Word 文档以及处理文件操作。
- 微信自动监听需要用户自行配置本地气泡检测组件；便携包可直接使用随 Release 提供的 YOLO 气泡模型，但不包含训练环境和数据集。

## 数据位置

- `data`：本机运行配置、人格、对话和调试截图。
- `.runtime`：Electron 运行时缓存。

这些目录均在便携包内生成，复制整个文件夹即可迁移配置。请勿把 API Key 提交到公共仓库或发送给他人。

## 开发检查

在 PowerShell 中运行：

```powershell
npm run check
npm test
```

## 卸载

双击项目根目录的 `uninstall-listagent.cmd`，输入 `DELETE` 后会停止本版本进程、移除本版本写入的资源管理器右键菜单，并删除当前安装目录。它不会触碰另一份安装或其他版本的注册表项。

## GitHub 更新

在控制面板“连接”页面填写公开仓库的 `owner/repository`，即可检查 GitHub Releases 并一键更新。点击更新后，按钮右侧会显示累计下载量（已下载 MB / 总计 MB）。`v0.2.9` 是兼容过渡版本，仅发布完整便携包；从 `v0.2.10` 起每个 Release 同时发布完整包和 `listagent-update-manifest.json` 增量清单。`0.2.9` 之前的客户端始终识别并下载完整包，`0.2.9` 及之后的客户端优先使用增量清单，缺少清单或 Electron 运行时变化时才回退完整包。更新会保留每位使用者的 `data`、`.runtime`、模型和本地素材。发布新版本时推送形如 `v0.2.1` 的标签，GitHub Actions 会按版本策略自动构建并发布相应资产。
