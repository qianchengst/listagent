# listagent

一个本地优先的 Windows 桌宠智能体：可换 GIF / WebM 动图形象、可编辑人格与语言示例、可连接 OpenAI 兼容的 Token API，并可在授权后执行有限的电脑操作。

## 已实现

- 透明置顶桌宠窗口仅显示 GIF 或 WebM 动图：左键拖动，右键交互。
- 桌宠左键仅用于拖动；右键单击打开轻量对话气泡，右键双击打开控制面板。
- 控制面板第五栏“个性化”提供皮肤一键切换：经典皮肤保留原本 UI，精修皮肤为无参考图的结构优化版本，拉普兰德皮肤保留深紫与暖金风格，佩佩皮肤提取长图参考中的暖米白纸张、紫色章节条、橙金标签与编辑式分段；第三版控制台背景使用纯色，不直接铺设海报图片。
- 可分别上传坐立、站立、互动、移动和删除状态的 GIF / WebM；移动结束后在坐立与站立之间随机切换，吸附到窗口时固定使用坐立动图；左键单击静止动作会播放一次互动动图。互动动图上限 100MB，其余动图上限 40MB。
- 无对话或自动化任务、且控制台关闭时，桌宠会以匀速间歇移动；速度约为初版最快移动速度的三分之一。
- 若检测到外部“始终置顶且未最大化”的窗口，下一次随机移动会随机停在该窗口顶部上方，模拟坐在窗口顶边；之后仍会继续间歇移动。
- 人格名称、使用者关系、人格设定、语言示例与模型连接参数的本地配置；使用者关系会参与模型的称呼和互动语气判断。
- 控制面板聊天头像可在“形象与人格”中上传 PNG、JPG、WebP 或 GIF（最大 10MB），头像只保存在项目 `data/avatars/` 中。
- OpenAI 兼容的 `POST /chat/completions` 双模型接口：纯文本模型负责普通对话和工具调用，视觉模型只负责截图识图；两组连接可使用不同的 Base URL、API Key 和模型；密钥只保存在项目 `data/settings.json`，读取页面时会隐藏。
- 微信监听采用 YOLO + 视觉 + 文本三级流程：本地 YOLOv8 先检测所有气泡并按纵坐标选出最后一条，判断 `other`（左侧灰/黑）或 `self`（右侧绿色）；只有 `other` 才把该气泡裁剪给视觉模型读取文字，随后交给带人格设定的纯文本模型，以使用者第一人称代笔生成可直接发送的回复。YOLO 未训练、检测不确定或文字为空时不会回复。
- 项目内置 `.venv-yolo`、训练脚本和持久化推理工作进程；调试窗口可保存截图到待标注目录，训练说明见 `yolo/README.md`。
- 自动化页面提供“打开识图调试”窗口，可直接截取并原样显示微信 PNG，不依赖视觉模型配置；随后可选执行 YOLO / 视觉识别，也可保存原始截图用于标注，手动调试不会发送微信消息。
- 微信截图优先使用 Electron 的窗口级捕获，避免硬件加速窗口被裁切；若系统不支持则回退到 PowerShell `PrintWindow`，调试窗口会显示实际截图方式和尺寸。
- 具备工具调用协议的智能体：打开网页、打开/恢复受限应用、检查微信窗口、向当前微信窗口粘贴并发送文字。
- 对“打开微信/记事本/计算器/资源管理器/设置”等明确指令提供本地意图兜底；也可按名称匹配 Windows 开始菜单中已安装的应用。即使文本模型没有返回标准工具调用，也会进入同一权限与执行流程。
- 模型可直接读取系统本地时间；可通过网络 IP 获取近似城市位置，并使用 Open-Meteo 查询实时天气/短期预报、使用 DuckDuckGo 查询网页摘要。上述只读信息工具不需要开启电脑操作权限，定位结果会明确标注为近似位置。
- 文档工具支持读取项目内 UTF-8 文本文件（`.txt`、`.md`、`.csv`、`.json` 等），以及使用本机 Microsoft Word 创建、读取和编辑 `.docx` 文档。读取属于只读工具；开启“自动执行已授权操作”后，新建文件可直接执行，覆盖、追加和编辑仍会要求确认。
- 人文关怀提醒默认开启：每分钟检查系统是否仍在活跃使用，结合连续使用时长、午间/晚间和夜间等场景，由纯文本模型完整读取人格设定后生成一句关怀话语，并在对话气泡中显示。最短提醒间隔默认 45 分钟、连续使用阈值默认 90 分钟，可在“自动化与微信”页面关闭或调整；离开电脑 15 分钟以上会重新计时，提醒不写入聊天历史。
- “陪伴记录”页面实时显示本次启动时长、累计陪伴时长、桌面移动距离、对话条数和模型 Token 用量；数据只保存在本机 `data/companion-record.json`，运行期间每 5 秒刷新一次。
- “自动化”页面可开启 Windows 开机自启动；登录后仅启动桌宠，控制面板保持隐藏，设置保存在本机并可随时关闭。
- 对“打开记事本、查询天气并记录”等复合指令，程序会先实际获取天气，再打开记事本，最后把结果整理成写入操作；新文件在开启自动执行时直接写入，否则进入确认流程。不会仅凭模型的一句回复判定任务已完成。
- 为避免模型误改系统文件，文档工具只允许访问项目目录或桌面目录；用户未指定路径时优先使用 `desktop/`，项目内可使用 `documents/`。`data/`、`.runtime/`、`node_modules/` 等内部目录会被拒绝访问。

## 运行

```powershell
npm install
npm start
```

首次启动后，右键单击桌宠打开对话气泡，右键双击打开控制面板。在「形象与人格」分别上传坐立、站立、互动、移动和删除状态的 GIF / WebM，并按需调整各自大小；在「连接」分别填写纯文本模型连接和视觉模型连接（Base URL、模型名、API Key）。视觉模型可以留空，但读取微信截图时必须配置支持图片输入的模型。

文档操作可直接在对话中提出，例如“阅读 desktop/计划.txt”“把 desktop/计划.txt 中的‘周一’改成‘周二’”或“创建一个会议纪要.docx”。未指定路径时，新文件默认保存到 Windows 桌面；读取会直接返回内容，编辑已有文件会进入确认流程。说“打开看看”“打开刚才的文件”时，会直接打开最近创建的文本文件；Word 文档功能需要本机已安装 Microsoft Word 桌面版。

人格设定与语言示例支持分别从 TXT 附件导入。导入会替换对应文本并立即保存在本地设置中，适合使用较长的人设档案或示例集。

## 微信说明

个人微信桌面版没有可供本项目稳定依赖的公开“读聊天记录 / 自动回复”接口。因此当前版本提供了桌面自动化桥接：可以恢复并置前微信、截取微信窗口、在对话中按需读取截图、比较截图变化，并在开启“微信监听与自动回复”后交给支持图片输入的模型判断是否有新消息。首次监听只建立画面基线；无法确认新消息时不会发送。

监听默认每 5 秒检查一次，可在控制台调整为 3—30 秒。截图只保存在项目的 `.runtime/wechat-captures/` 运行目录中，自动回复还要求同时开启“自动执行已授权操作”。

若需要真正的事件驱动消息机器人，应使用企业微信、公众号或小程序的官方消息接口，并在后续接入相应账号凭据与回调地址。

## 数据位置

所有项目数据都位于此项目目录：

- `data/settings.json`：本地设置（含 API Key，请勿提交或分享）
- `data/pets/`：上传的桌宠 GIF / WebM 动图
- `data/avatars/`：控制面板聊天使用的用户头像图片
- `yolo/dataset/`：微信气泡标注数据集；`models/wechat-bubbles.pt`：训练后的 YOLO 模型
- `.runtime/`：Electron 运行时文件

## 安全模型

模型不会得到任意 shell 命令执行能力。它只能请求预定义工具；自动化开关关闭时工具请求会被阻止。发送微信前会尝试恢复并激活微信窗口，无法确认可用窗口时不会发送。

## 卸载

双击项目根目录的 `uninstall-listagent.cmd`，输入 `DELETE` 后会停止本版本进程、移除本版本写入的资源管理器右键菜单与开机自启动项，并删除当前安装目录。它不会触碰另一份安装或其他版本的注册表项。

## GitHub 更新

在控制面板“连接”页面填写公开仓库的 `owner/repository`，即可检查 GitHub Releases 并一键更新；新安装和历史空白配置会自动填入 `qianchengst/listagent`。点击更新后，按钮右侧会显示累计下载量（已下载 MB / 总计 MB）。`v0.2.9` 是兼容过渡版本，仅发布完整便携包；从 `v0.2.10` 起每个 Release 同时发布完整包和 `listagent-update-manifest.json` 增量清单。`0.2.9` 之前的客户端始终识别并下载完整包，`0.2.9` 及之后的客户端优先使用增量清单，缺少清单或 Electron 运行时变化时才回退完整包。更新会保留每位使用者的 `data`、`.runtime`、模型和本地素材。发布新版本时推送形如 `v0.2.1` 的标签，GitHub Actions 会按版本策略自动构建并发布相应资产。
