更新来源

Gitee 需要仓库先发布同名 Release 和 Windows 完整包；GitHub 仍支持增量更新。

模型分工

普通对话、工具调用和自动化指令使用纯文本连接；只有读取微信截图时才调用视觉连接。两组连接可以分别使用不同平台、Base URL、API Key 和模型。

应用更新

可从 Gitee（国内源）或 GitHub（国外源）检查 Windows 便携版更新。GitHub 新版会优先下载变化文件；Gitee Release 为完整包。人格、API 设置、聊天记录、模型和桌宠素材都会保留。

本地执行

运行设置

控制智能体能否操作电脑，以及 Windows 登录后是否自动启动。

允许智能体执行电脑操作

开启后，启动或恢复应用可直接执行；关闭时所有电脑操作都会被阻止。

自动执行已授权操作

开启后，截图、微信输入和新建文件等操作会直接执行；覆盖、追加和编辑文件仍会弹窗确认。

开机自启动

登录 Windows 后自动启动桌宠，控制面板保持隐藏；可随时关闭。

定时执行

安排桌宠的自然移动、休息状态和主动关怀提醒。

启用休息状态

开启后桌宠会贴住屏幕底部并暂停自然移动；再次关闭即可恢复自然移动。

自然移动频率

桌宠每次移动结束后会静止一段时间，再随机移动。两个控制点决定静止时间范围，采用非线性刻度：10 秒至 10 分钟。

10 秒30 秒1 分3 分10 分
最短静止 30 秒最长静止 90 秒

拖动圆点或点击刻度调整，松开后自动保存。

人文关怀提醒

桌宠会根据连续使用时长、系统空闲状态和时间段，偶尔用你的人格设定生成一句关心的话，并在气泡中显示。不会读取具体屏幕内容。

电脑连续活跃时才会计时；离开电脑 15 分钟以上会重新开始计算。提醒不会加入聊天历史。

窗口控制

恢复应用窗口，或让桌宠坐到当前的置顶窗口上。

微信窗口

可自动恢复并置前微信，也可检查当前可用窗口和尺寸。

可用工具

读取当前时间、联网搜索、查询天气和大致位置；打开网页、启动或恢复常用应用，或按名称匹配 Windows 开始菜单中已安装的应用。模型无法执行任意命令或任意路径。

坐到置顶窗口

优先寻找置顶且未最大化的窗口；如果没有，则使用当前前台且未最大化的窗口。桌宠会移动到窗口上方并坐下，之后仍会按当前自动移动规则偶尔离开。

外部通知

监听微信窗口中的新消息，并根据权限自动拟写回复。

微信监听与自动回复

监听先用本地 YOLO 检测纵坐标最低气泡属于对方还是自己，再只对对方气泡调用视觉模型读取文字，最后交给文本模型生成回复。YOLO 未训练或未检测到可信气泡时不会回复。首次启动只建立画面基线，不会立即回复。

远程控制

查看模型可以使用的工具，以及文件删除的安全边界。

资源管理器右键删除

Windows 文件右键菜单已加入“通过 listagent 删除”。点击后桌宠会移动到当前文件操作位置，播放“删除文件时”动画（未设置时沿用移动动图），然后将文件移入回收站。

自动回复必须同时开启“自动执行已授权操作”。YOLO 无法确认气泡、视觉模型无法读取文字或文字已处理过时，不会发送消息。
