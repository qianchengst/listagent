应用更新

从 GitHub Releases 检查 Windows 便携版更新。新版会先下载更新清单，只传输本机缺少或已变化的程序文件；仅旧 Release 没有清单或 Electron 运行时发生变化时才回退下载完整包。人格、API 设置、聊天记录、模型和桌宠素材都会保留。

受控执行

自动化

允许智能体执行电脑操作

开启后，启动或恢复应用可直接执行；关闭时所有电脑操作都会被阻止。

自动执行已授权操作

开启后，截图、微信输入和新建文件等操作会直接执行；覆盖、追加和编辑文件仍会弹窗确认。

开机自启动

登录 Windows 后自动启动桌宠，控制面板保持隐藏；可随时关闭。

自然移动频率

桌宠每次移动结束后会静止一段时间，再随机移动。两个控制点决定静止时间范围，采用非线性刻度：10 秒至 10 分钟。

最短静止 30 秒最长静止 90 秒

拖动圆点或点击刻度调整，松开后自动保存。

人文关怀提醒

桌宠会根据连续使用时长、系统空闲状态和时间段，偶尔用你的人格设定生成一句关心的话，并在气泡中显示。不会读取具体屏幕内容。

电脑连续活跃时才会计时；离开电脑 15 分钟以上会重新开始计算。提醒不会加入聊天历史。

可用工具

读取当前时间、联网搜索、查询天气和大致位置；打开网页、启动或恢复常用应用，或按名称匹配 Windows 开始菜单中已安装的应用；也可检查微信进程，并在需要时截取微信窗口。模型无法执行任意命令或任意路径。

微信窗口

可自动恢复并置前微信，也可检查当前可用窗口和尺寸。

坐到置顶窗口

优先寻找置顶且未最大化的窗口；如果没有，则使用当前前台且未最大化的窗口。桌宠会移动到窗口上方并坐下，之后仍会按当前自动移动规则偶尔离开。

微信监听与自动回复

监听先用本地 YOLO 检测纵坐标最低气泡属于对方还是自己，再只对对方气泡调用视觉模型读取文字，最后交给文本模型生成回复。YOLO 未训练或未检测到可信气泡时不会回复。首次启动只建立画面基线，不会立即回复。

资源管理器右键删除

Windows 文件右键菜单已加入“通过 listagent 删除”。点击后桌宠会移动到当前文件操作位置，播放“删除文件时”动画（未设置时沿用移动动图），然后将文件移入回收站。

自动回复必须同时开启“自动执行已授权操作”。YOLO 无法确认气泡、视觉模型无法读取文字或文字已处理过时，不会发送消息。
